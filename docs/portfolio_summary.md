# 📋 Perfumance 포트폴리오 프로젝트 요약 (Portfolio Summary)

본 문서는 개발자 채용 담당자를 위해 프로젝트의 핵심 기여도, 해결한 문제, 핵심 성과를 집약한 요약 리포트입니다.

---

## 🚀 1. 핵심 기여 요약 (Key Accomplishments)

* **하이브리드 추천 엔진 설계**: 사주(오행 균형론) 벡터와 유저 선호/비선호 향조 벡터를 병합 연산하는 하이브리드 추천 시스템 설계. 행동 이력이 없는 신규 사용자에게도 추천 근거를 제공하는 초기 추천을 수행함.
* **추천 정책 고도화 (BASELINE ➡️ BALANCED)**: 단순 유명 브랜드 가점에 따른 편향을 완화하고 브랜드 보너스를 최종 점수에 `+0.03` 가산으로 축소하여 사용자 선호 향조의 반영 비중을 높임.
* **데이터 정제 & 파이프라인 개발**: 4,298개의 원본 향수 데이터를 안전하게 탐색하고 360건의 브랜드 표기 불일치를 정규화하여 **4,292개**의 정제된 마스터 데이터셋으로 가공하는 ETL/정제 파이프라인 수립.
* **LLM Fallback 구조 구현**: `gemini-flash-latest` 모델을 사용한 설명 생성 중 API 키 누락 시 즉시, 네트워크 지연 시 30초 타임아웃 후, 혹은 429, 500, JSON 파싱 오류 시 규칙 기반 대체 응답으로 전환되는 안정적인 Fallback 아키텍처 도입하여 AI 장애에도 핵심 추천 결과 유지.
* **72개 pytest 스위트 통과**: 윤년 경계치, 향조 오탐(pear vs spearmint), 브랜드 정규화 예외 케이스 등 72개 조건의 유닛/통합 테스트를 통과하고 프로덕션 배포 완료.

## ⚡ 2. 핵심 문제 해결 스토리 (Problem Solving Story)

### 📌 Case 1: 향조 텍스트 부분 매칭으로 인한 오탐 해결
* **상황**: 향수의 영문 노트 단어에 대한 포함 여부를 확인하기 위해 일반 문자열 검색을 수행할 때, `spearmint`(스피어민트)라는 단어가 포함된 향수에 `pear`(서양배) 향조를 좋아하는 유저를 위한 추천 점수가 오가산되는 현상 발견.
* **해결**: 단어 경계(`\b`) 정규식 패턴과 토큰 분리 비교를 적용한 **Token Boundary Matching**을 구현하여 단어의 일부로 쓰인 스펠링을 매칭 대상에서 제외함으로써, 추천 결과 오탐 가능성을 줄임.

### 📌 Case 2: 브랜드 가점 쏠림으로 인한 추천 편향성 개선
* **상황**: BASELINE 정책의 유명 브랜드 보너스(최종 점수에 +0.15 가산)가 너무 커 유저가 입력한 비선호 향조(예: 바닐라)가 미세하게 섞여 있는 제품이 탑 3에 추천되는 부작용 식별.
* **해결**: 브랜드 보너스를 최종 점수에 `+0.03` 가산으로 축소하고 취향 반영 가점/감점 비중을 `0.35` / `-0.35` 수준으로 상향 조정한 `BALANCED` 추천 정책을 재구축하여, 유저가 설정한 선호 향조와 오행에 매칭되는 향수군이 고르게 추천되도록 개선함.

### 📌 Case 3: Structured Output 장문 JSON 잘림 문제 대응
* **상황**: Google GenAI SDK를 통해 Gemini 모델에 엄격한 Schema 형태의 Response JSON 출력을 요구하였을 때, 장문의 사주 풀이를 생성하는 과정에서 최대 출력 토큰 한계 또는 문장 중단으로 인해 JSON 끝단 괄호가 잘려나가는 JSON 파싱 오류가 발생하여 화면이 강제 종료되는 문제가 있었습니다.
* **해결**: 스키마 제약 대신 일반 JSON 출력 모드로 변경하여 충분한 여유 토큰 버퍼를 제공하도록 유도하고, 받아온 로우 데이터를 파싱하여 백엔드에서 **Pydantic 사후 유효성 검증(Schema Validation)** 과정을 거치도록 코드를 재설계했습니다. 데이터 누락 또는 스키마 포맷 오류 발생 시 깨진 JSON을 억지로 노출하지 않고 폐기 처리합니다.

## 📸 3. 필요한 화면 캡처 가이드 (Screen Capture Checklist)

포트폴리오에 시각 자료로 첨부하기 위해 캡처해야 할 핵심 화면 목록과 목적입니다.

1. **사주 및 취향 입력 화면 (Next.js Main)**
   * *캡처 목적*: 반응형 UI 구조, 생년월일시 선택 셀렉터 및 선호/비선호 태그 UI의 편의성 시각화.
2. **사주 분석 결과 오행 밸런스 시각화 (Result Detail)**
   * *캡처 목적*: 사용자의 오행(목/화/토/금/수) 분포가 차트로 표현되는 시각화 결과.
3. **최종 추천 향수 카드 & 매칭 요약 (Top 3 Cards)**
   * *캡처 목적*: 선정된 향수의 오행 비율, 매칭 점수, 브랜드 이미지가 카드 레이아웃으로 출력되는 모습 제시.
4. **Gemini 생성 맞춤해설 (Analysis Story)**
   * *캡처 목적*: "당신의 쇠(Metal) 기운을 채워줄 시원한 민트 노트" 등 도메인 지식과 인공지능이 자연스럽게 결합된 문장 품질 검증.
5. **BASELINE / BALANCED 비교 화면**
   * *캡처 목적*: 추천 정책 변경에 따른 탑 순위 추천 결과의 변화를 비교.
