# Perfumance Phase 4-3 결측·오염 데이터 우선순위화 보고서

본 보고서는 결측 및 오염이 포함된 향수들을 실제 추천 시뮬레이션의 노출 빈도 기준으로 우선순위(P1/P2/P3)로 매핑하고 가공한 보고서입니다.

## 1. 우선순위 분류 지표

- **P1 (자주 추천되는 핵심 제품, 노출수 >= 5)**: 0개
- **P2 (가끔 추천되는 제품, 노출수 1~4)**: 5개
- **P3 (추천에 거의 미노출되는 제품, 노출수 0)**: 76개
- **자동으로 인코딩/웹문구가 정제된 건수**: 0건
